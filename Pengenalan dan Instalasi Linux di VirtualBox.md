### 1. Navigasi & Manajemen Direktori
| Perintah | Penjelasan Singkat |
| :--- | :--- |
| `ls` | Menampilkan daftar file dan folder di direktori saat ini. |
| `ls -la` | Menampilkan semua file, termasuk yang tersembunyi (dotfiles). |
| `ls -l` | Menampilkan daftar file dalam format list panjang dengan detail. |
| `mkdir [nama]` | Membuat folder atau direktori baru. |
| `cd [nama_folder]` | Berpindah atau masuk ke folder tertentu. |
| `cd ..` | Kembali ke satu tingkat folder di atasnya. |
| `cd /` | Berpindah langsung ke direktori utama (root) sistem. |

### 2. Pengelolaan & Pencarian File
| Perintah | Penjelasan Singkat |
| :--- | :--- |
| `cp` | Menyalin (copy) file atau folder. |
| `mv` | Memindahkan (move) atau mengubah nama file/folder. |
| `rm` | Menghapus file secara permanen. |
| `cat` | Menampilkan isi file teks secara cepat di terminal. |
| `grep` | Mencari kata atau pola tertentu di dalam teks atau file. |

### 3. Update & Pemeliharaan Sistem
| Perintah | Penjelasan Singkat |
| :--- | :--- |
| `sudo apt update` | Memperbarui daftar paket/aplikasi dari repositori. |
| `sudo apt upgrade` | Mengunduh dan menginstal pembaruan aplikasi yang terpasang. |
| `sudo apt full-upgrade` | Upgrade sistem secara total termasuk penyesuaian dependensi. |
| `sudo apt autoremove` | Menghapus paket-paket sisa yang sudah tidak dibutuhkan. |
| `sudo apt clean` | Membersihkan file sampah sisa instalasi aplikasi. |

### 4. Instalasi & Lingkungan Python
| Perintah | Penjelasan Singkat |
| :--- | :--- |
| `sudo apt install python3` | Menginstal bahasa pemrograman Python 3 ke dalam sistem. |
| `python3 --version` | Mengecek versi Python 3 yang sedang terpasang. |
| `sudo apt install python3-pip` | Menginstal pengelola paket (pip) untuk library Python. |
